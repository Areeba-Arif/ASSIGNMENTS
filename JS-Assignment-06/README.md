## 📌 Question 1 — Basic Array Methods

**Folder:** `Q1`

### Description

A fruits array is created with at least five fruit names. Different array properties and methods are used to access and display its elements.

### Methods Practiced

* `length` — finds the number of elements.
* `toString()` — converts the array into a string.
* `at()` — accesses elements using positive and negative indexes.
* `join()` — combines array elements using a chosen separator.

### Concepts

* Array creation
* `length`
* `toString()`
* `at()`
* `join()`
* `console.log()`

## 📌 Question 2 — Adding and Removing Array Elements

**Folder:** `Q2`

### Description

A students array is created with at least five student names. Students are added and removed from both the beginning and end of the array.

### Methods Practiced

* `push()` — adds an element to the end.
* `pop()` — removes and displays the last element.
* `unshift()` — adds an element to the beginning.
* `shift()` — removes and displays the first element.
* `length` — displays the final number of students.

The array is displayed after each operation to observe how the array changes.

### Concepts

* `push()`
* `pop()`
* `unshift()`
* `shift()`
* `length`
* `console.log()`

## 📌 Question 3 — concat(), slice(), splice() and delete

**Folder:** `Q3`

### Description

Two arrays are created to practice combining, copying, modifying, and deleting array elements.

### Methods Practiced

* `concat()` — combines two arrays into a new array.
* `slice()` — creates a copy of a selected portion of an array.
* `splice()` — removes and adds elements at a specific position.
* `delete` — removes an element using its index.

After using `delete`, the array and its length are displayed to observe that the position becomes empty while the array length remains unchanged.

### Concepts

* `concat()`
* `slice()`
* `splice()`
* `delete` operator
* Difference between `delete` and `splice()`
* `console.log()`

## 📌 Question 5 — Mini Array Management Program

**Folder:** `Q5`

### Description

A small Product List Manager is created using the array concepts covered throughout the assignment.

The program performs different operations on a products array, including adding, removing, combining, copying, modifying, and displaying products.

### Methods Practiced

* `length` — displays the number of products.
* `at()` — accesses the first and last products.
* `push()` / `unshift()` — add products.
* `pop()` / `shift()` — remove products.
* `concat()` — combines product arrays.
* `slice()` — creates a smaller product list.
* `splice()` — replaces or removes a product.
* `join()` — converts the final product list into a string.
* Arrow function — displays the final array.
* `Array.isArray()` — verifies that the final list is an array.
