# HTML Basics — Assignment 01

This folder contains my first assignment for the Backend Development course.

## 📖 Assignment Overview

This assignment focuses on the fundamentals of HTML5 and the creation of basic webpages using HTML.

The assignment consists of four tasks covering different HTML concepts.

## 📝 Tasks

### 1. My Introduction

A basic HTML webpage introducing myself.

**Concepts covered:**

* HTML5 document structure
* `<h1>` and `<h2>` headings
* Paragraphs
* Unordered lists
* Ordered lists

### 2. My Favorite Websites

A webpage containing frequently used websites and a clickable image.

**Concepts covered:**

* Links using `<a>`
* `target="_blank"`
* Images using `<img>`
* `alt` attribute
* Making an image clickable

### 3. Student Marks

A webpage displaying student marks in a table.

**Concepts covered:**

* `<table>`
* `<tr>`
* `<th>`
* `<td>`
* `<caption>`

### 4. Student Registration Form

A student registration form containing different types of input fields.

**Concepts covered:**

* Text input
* Email input
* Password input
* Date input
* Radio buttons
* Checkboxes
* Dropdown/select menu
* Textarea
* Labels
* Submit and reset buttons
* Required fields

## 📁 Files

| File                | Description               |
| ------------------- | ------------------------- |
| `introduction.html` | My Introduction webpage   |
| `websites.html`     | Favorite Websites webpage |
| `marks.html`        | Student Marks table       |
| `registration.html` | Student Registration Form |

## 🛠️ Technologies Used

* HTML5

## ▶️ How to Run

Open any `.html` file in a web browser to view the webpage.
