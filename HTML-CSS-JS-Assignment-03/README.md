# HTML, CSS & JavaScript Basics — Assignment 03

This folder contains a collection of web development pages built using **HTML5**, **CSS3**, and **JavaScript**. The assignment focuses on **CSS Grid**, **Responsive Design**, **Media Queries**, **DOM Manipulation**, and **JavaScript Variables & Data Types**.

---

## 📁 Included Files & Projects

- **`CSS_Grid.html`** & **`CSS_Grid.css`**
  - A responsive webpage layout created using **CSS Grid**.
  - Uses breakpoints and **Media Queries** to adjust the layout for desktop, tablet, and mobile screen sizes.

- **`q2_DOM.html`** & **`q2_Script.js`**
  - Demonstrates basic **DOM Manipulation** using JavaScript.
  - Uses `getElementById()`, `alert()`, `console.log()`, and `document.write()`.

- **`q3_Variable.html`** & **`q3_Script.js`**
  - Demonstrates JavaScript **variables and data types**.
  - Includes `var`, `let`, and `const`, along with String, Number, Boolean, Undefined, Null, Object, Array, Symbol, and BigInt examples.

---

## 🛠️ Concepts & Technologies Applied

- **HTML5:** Semantic structure and webpage elements.
- **CSS3:** CSS Grid, responsive layouts, breakpoints, Media Queries, styling, spacing, and alignment.
- **JavaScript:** DOM manipulation, variables, data types, `typeof`, `alert()`, `console.log()`, and `document.write()`.
