# HTML & CSS Basics — Assignment 02

This folder contains a collection of web development pages built using **HTML5** and **CSS3**. The assignment focuses on applying CSS layout techniques—including **Flexbox**, **Positioning**, **Responsive Design**, and custom table/form styling—to build structured and interactive web components.

---

## 📁 Included Files & Projects

* **`introduction.html`**
  * A personal introduction page detailing background, interests, and goals.
  * Demonstrates the use of Inline, Internal CSS, styled lists, and highlight blocks.

* **`registration.html` & `registration.css`**
  * A complete **Student Registration Form**.
  * Built with structured form elements (text inputs, date selectors, radio buttons, checkboxes, dropdowns, textareas, submit/reset buttons) styled using CSS positioning and Flexbox alignment.

* **`marks.html` & `marks.css`**
  * A formatted **Student Marks Table** displaying student grades and totals.
  * Styled with custom table headers, borders, cell padding, and highlight classes.

* **`websites.html` & `websites.css`**
  * A showcase page featuring favorite external web resources (Google, YouTube, GitHub, Coursera).
  * Integrates styled hyperlinked text and interactive image links opening in new tabs (`target="_blank"`).
 
* **`profile.html` & `profile.css`**
  * A personal portfolio profile page featuring a navigation bar, interactive skill badges, structured journey section, and footer
  * Features a **Flexbox** layout for sections, rounded profile photo, and responsive design units (`vh`, `%`, `rem`)

* **`flexbox.html` & `flexbox.css`**
  * A modern software landing page named *Landflow*
  * Utilizes **Flexbox** column and row layouts, curved hero gradient background, interactive buttons, and elevated feature cards[cite: 1, 2].


---

## 🛠️ Concepts & Technologies Applied

* **HTML5:** Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`, `<form>`, `<table>`).
* **CSS Layouts:** Flexbox alignment (`display: flex`, `justify-content`, `align-items`, `flex-wrap`, `flex-direction`).
* **Styling Techniques:** Linear gradients, box shadows, border radii, hovering effects, and responsive unit usage (`rem`, `%`, `vh`).
* **Forms & Tables:** Form input validation attributes, custom select menus, flexible option containers, and custom table cell highlighting.
