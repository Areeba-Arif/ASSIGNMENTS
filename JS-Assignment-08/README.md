## 📌 Questions Covered

### Q1 — Online Store Sales Report
Analyzes order amounts using array searching, filtering, and reducing to find large orders and calculate total sales.

### Q2 — Student Performance Analyzer
Processes student marks using `map()`, `filter()`, `find()`, and `reduce()` while keeping the original marks unchanged.

### Q3 — Employee Data from an API
Works with employee objects to filter IT department employees, find employees based on salary, extract employee names, and calculate total salaries.

### Q4 — Store Inventory Using JavaScript Map
Manages product quantities using JavaScript `Map`, including adding, updating, retrieving, checking, deleting, iterating, and clearing entries.

### Q5 — Student Result Object
Creates student objects with subject marks and a method to calculate total marks and percentage. Demonstrates property access, `this`, and deleting an object property.

## 🛠️ Concepts Used

- Array methods: `find()`, `filter()`, `reduce()`, and `map()`
- Arrow functions
- JavaScript objects and properties
- Dot notation and bracket notation
- Object methods and the `this` keyword
- JavaScript `Map`
- `forEach()` and Map operations
