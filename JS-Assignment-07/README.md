# JavaScript Basics — Assignment 07

## Array Search, Sorting & JavaScript Objects

This assignment focuses on JavaScript array searching, sorting, array methods, arrow functions, and JavaScript objects and their methods.

The assignment contains six questions, with each question organized in a separate folder.

## 📌 Questions Covered

### Q1 — Student Search System
Works with student names and demonstrates searching for students, finding first and last occurrences, and checking positions based on conditions.

### Q2 — Product Price Organizer
Works with product prices and demonstrates ascending and descending sorting, reversing arrays, and generating a random ordering.

### Q3 — Class Result Analysis
Works with student marks and demonstrates combining arrays, selecting portions of arrays, changing and removing elements, checking array length, sorting, reversing, and using an arrow function.

### Q4 — Employee Record Object
Creates an employee object and demonstrates object properties, dot notation, bracket notation, adding properties, changing properties, and deleting properties.

### Q5 — Employee Object Methods
Extends employee objects by adding methods. It demonstrates creating methods, returning employee information, and using `this` to access object properties.

### Q6 — Product Inventory Mini Project
Combines arrays, objects, searching, sorting, conditions, and array methods to create a simple product inventory system.
